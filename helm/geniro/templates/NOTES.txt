=== Important Notes ===

1. CREDENTIAL_ENCRYPTION_KEY: This key encrypts all stored credentials (GitHub PATs,
   API keys, etc.). Back it up securely. If lost, all stored credentials become
   unrecoverable.

2. Frontend Config: The Web image has API_URL compiled in at build time via
   geniro-web/src/config/production.ts. If you are using custom domains, you must
   edit production.ts and rebuild the web image before deploying.

3. Docker Socket: The API mounts the host Docker socket for tool execution containers.
   If your cluster does not allow this, set api.mountDockerSocket=false and configure
   Daytona as the runtime instead (daytona.enabled=true).

4. Ingress Controller: If you enabled ingress, ensure an ingress controller
   (e.g., ingress-nginx) is installed in your cluster.

=== Useful Commands ===

Watch pod status:
  kubectl get pods -n {{ .Release.Namespace }} -w

Verify API is running:
  kubectl rollout status deployment/{{ include "geniro.fullname" . }}-api -n {{ .Release.Namespace }}

View API logs:
  kubectl logs -n {{ .Release.Namespace }} -l app.kubernetes.io/component=api -f
